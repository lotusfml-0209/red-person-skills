# 红人营销报价与预算模型

## 目标

把红人合作需求转换成：

1. 可解释的报价区间，而不是单点数字；
2. 基础发布费、制作费、渠道分发费、授权费分开列示；
3. 可谈判的保底方案、标准方案和增强方案；
4. 面向品牌内部审批和对外商务沟通都能使用的口径。

默认公司画像：高端 AI wearable / smart ring / Companion AI 品牌，重点市场为美国、英国、加拿大、德国、法国及其他欧洲市场。若用户提供了不同品牌画像、平台或地区，以用户输入覆盖默认值。

本 Skill 的默认使用方式是“前置基准 + 后续自主判断”：用户只需先提供粉丝量、平均播放/曝光、对方报价和时长/周期等基础信息；后续文本中出现的内容形式、脚本要求、测试深度、授权、投流、修改次数、发布时间等信息由 Skill 自行识别并纳入校正。

## 核心公式

建议报价 = 预计播放量 / 1000 × 内容 CPM × 地区系数 × 垂类系数 × 交付系数 × 分发系数 × 授权系数 + 制作基础费

当预计播放量不可靠时，使用“近 10 条内容中位播放量”作为基准，并同时给出保守值（P25）与乐观值（P75）。不得直接用粉丝数代替播放量；只能将粉丝层级作为合理性校验。

## 默认参数

| 参数 | 默认值 | 使用说明 |
|---|---:|---|
| YouTube 插播 CPM | 25–45 USD | 60–90 秒整合或中段口播 |
| YouTube 完播/深度测评 CPM | 50–90 USD | 独立视频、深度测评、完整体验 |
| 美国/英国/加拿大 | 1.20–1.50 | 受众主要来自这些国家时使用 |
| 德国/法国 | 1.00–1.25 | 德语/法语内容需额外确认本地化成本 |
| 西班牙/瑞典/其他欧洲 | 0.85–1.10 | 按受众国家混合占比加权 |
| 科技/3C复杂度 | 1.15–1.40 | 需要实测、数据解释、App 配对或技术教育时提高 |
| Shorts / IG Reels / TikTok 分发 | 1.10–1.25 | 作为同一创意的额外分发，不等同于单独买断 |
| 商用授权 / 二剪 / 投流 | 1.20–1.80 | 按授权期限、地区、媒介和是否白名单投流拆分 |

截图中的“粉丝/均播档位”只作为快速 sanity check：小号（1–5 万或均播 5k–20k）约 800–2,500 USD；小中腰（5–10 万或均播 20k–50k）约 2,000–4,500 USD；中腰（10–50 万或均播 50k–150k）约 4,000–9,000 USD；大中腰（50–100 万或均播 100k–250k）约 8,000–15,000 USD；头部（100 万以上或均播 250k+）约 12,000–25,000+ USD。若该档位与公式结果冲突，优先解释差异，不要机械取高价。

## 工作流程

### 0. 自动判断模式

当用户提供红人资料或对方报价时，自动进入“报价校正模式”，不要只复述资料。按以下顺序完成：

1. 规范化平台、币种、粉丝量、播放量、内容形式和授权范围；
2. 估算可比播放量与合理报价区间；
3. 将对方报价转换为“每千次有效观看成本（eCPM）”；
4. 判断报价是偏低、合理、偏高还是无法判断；
5. 给出影响判断的证据、缺失字段和可执行的谈判建议。

自动判断必须保留输入假设。任何由粉丝量推导播放量的结果都标注“模型估算”，不得伪装成红人的真实数据。

### 自动判断输入格式

接受自然语言、表格或 JSON。优先识别以下字段：

```text
平台：YouTube / YouTube Shorts / Instagram / TikTok / 其他
内容形式：插播 / 独立视频 / 深度测评 / 短视频 / 多平台组合
粉丝量：数字
近10条播放量：可填列表；至少给平均值或中位数
受众国家：国家及占比（如 US 60%, UK 20%）
垂类：科技/3C/AI wearable/生活方式/其他
交付：视频时长、数量、发布时间、链接、置顶评论等
额外分发：Shorts、Reels、TikTok、品牌自有渠道
授权：自然发布、品牌转发、二剪、投流/白名单、期限、地区
对方报价：数字、币种，以及是否包含制作/授权/税费/样机
```

只提供粉丝量而没有播放量时，使用平台观看率启发式估算可比播放量，并降低置信度：YouTube 长视频 10%–25%、Shorts 8%–25%、Instagram 5%–15%、TikTok 10%–30%。这些是内部估算区间，不是平台保证值；如用户提供近 10 条数据，必须优先使用真实数据。

### 最小前置输入

如果用户不想填写完整表格，至少提取以下 4 项作为前置判断信息：

```text
粉丝量：账号规模校验
平均播放/曝光：优先使用近 10 条中位数；没有时可暂缺
对方报价：数字与币种
时长/周期：视频时长、合作周期或授权周期；若语义不明确，分别列出假设
```

之后自动阅读用户补充的所有合作说明，识别并修正：平台、国家、内容形式、科技复杂度、交付数量、发布时间、额外分发、授权、独家、投流、样机、差旅、税费和修改次数。不要因为用户没有按字段填写就停止判断。

“时间”存在歧义时，按上下文区分为：内容时长（如 60 秒口播）、制作周期（如 14 天交付）或授权期限（如 30 天投流）；无法区分时同时给出两种影响，不擅自合并。

### 报价合理性判断

对方报价与模型区间必须在“同口径”下比较：自然发布费、制作费、授权费、投流费、差旅/税费不能混在一起后再直接比较。

先计算：

`对方 eCPM = 可比总价 ÷ 预计播放量 × 1000`

再计算：

`报价倍数 = 对方可比总价 ÷ 模型标准报价中点`

默认标签：

- `0.60 以下：明显偏低`——检查是否漏算授权、制作、税费或交付内容；也可能是数据质量差。
- `0.60–0.80：偏低，可谈`——适合试投，但要检查交付可靠性和账号真实性。
- `0.80–1.20：基本合理`——与模型主区间一致。
- `1.20–1.50：偏高但可能合理`——必须有强受众匹配、稀缺地区、稳定高完播、复杂制作或授权价值支撑。
- `1.50 以上：明显偏高`——除非是头部稀缺资源、发布节点稀缺、独家或大范围投流授权，否则建议重谈或拆项。

若报价缺少播放量，改用粉丝量档位作交叉校验；若报价同时远高于 CPM 模型和粉丝档位，输出“高风险偏高”。若两种模型冲突，展示冲突原因，不强行给出确定结论。

### 置信度

自动输出 `高 / 中 / 低` 三档置信度：

- 高：有近 10 条播放量、受众国家占比、明确交付和授权条款；
- 中：有平均/中位播放量，但缺少受众拆分或授权细节；
- 低：只有粉丝量、平台和一个总报价。

置信度低时，结论只能写成“初筛”，并列出获取更准确判断所需的 3 个最关键数据。

### 1. 先补齐输入

至少确认：平台、内容形式、预估播放量或近 10 条中位播放量、受众国家占比、是否为科技/3C深度内容、交付数量、发布时间、是否需要额外分发、授权期限与用途、是否需要独家、是否含差旅/样机/税费。

缺失信息时可以先估算，但必须标注“暂估”，并列出会显著改变价格的变量。

### 2. 计算三档方案

- 保守档：P25 播放量 + 区间低值系数，适合试投或预算敏感项目。
- 标准档：中位播放量 + 区间中值系数，作为对外主报价。
- 增强档：P75 播放量 + 复杂制作/额外分发/授权，适合品牌重点合作。

每档都要给出：创作者到手/媒体费、制作基础费、额外分发费、授权费、预计总价，以及可谈判项。

### 3. 对 AI wearable / 3C 场景做校正

以下情况通常提高垂类与制作系数：需要佩戴周期、睡眠/健康/运动场景实测；需要 App 连接、数据截图、对比竞品；需要准确解释 AI 功能、隐私或订阅机制；需要海外物流、样机回收或多语言字幕。

以下情况可降低系数或拆成单独选项：品牌只需 30–60 秒口播；素材由品牌提供；不要求深度测评；只购买自然发布、不含广告投流及二次使用。

不要把医疗功效、健康诊断或绝对性能承诺写入报价模型；这类内容应标记为合规审查项。

### 4. 输出报价建议

默认用人民币和 USD 双币种（汇率注明“以签约日为准”），并使用以下结构：

| 项目 | 建议内容 |
|---|---|
| 合作目标 | 品牌认知 / 产品教育 / 转化 / 发布会放大 |
| 主方案 | 平台、内容形式、预计播放量、发布时间 |
| 公式 | 展示实际使用的各项参数 |
| 价格区间 | 保守 / 标准 / 增强三档 |
| 包含内容 | 脚本、拍摄、剪辑、发布、链接、评论区置顶等 |
| 不包含内容 | 样机、差旅、税费、额外修改、授权、投流等 |
| 授权与使用 | 期限、地区、媒介、是否允许二剪/白名单 |
| 风险提示 | 播放量不保证、平台波动、合规审查、库存/物流 |
| 谈判底线 | 可让步项与不可让步项 |

## 谈判规则

- 先谈交付范围与使用权，再谈总价；不要只压 CPM。
- 允许让步时优先缩短授权期限、减少二剪版本、降低额外分发数量，尽量保留创作者基础制作费。
- “自然发布 + 品牌自有渠道转发”与“付费投流/白名单”必须分开报价。
- 独家按竞品范围、地区和期限单独计价，不默认包含在发布费中。
- 不承诺播放量；如品牌必须要量，改为保底曝光、补发条款或追加投流预算，并写明触发条件。
- 对多个创作者进行比较时，使用“有效观看成本 + 内容资产价值 + 受众匹配度”，不要按粉丝数排序。

## 默认输出模板

先给结论：推荐总预算区间、主推方案和最大影响变量。

然后给计算：

`预计播放量 ÷ 1000 × CPM × 地区系数 × 垂类系数 × 交付系数 × 分发系数 × 授权系数 + 制作基础费`

最后给商务口径：包含项、不包含项、授权边界、可谈判项、下一步需要向红人确认的问题。

当用户提供对方报价时，必须额外输出：

```text
判断：明显偏低 / 偏低可谈 / 基本合理 / 偏高但可能合理 / 明显偏高 / 暂无法判断
模型合理区间：USD X–Y
对方报价：USD Z
报价倍数：Z ÷ 模型标准报价中点
对方 eCPM：USD N
置信度：高 / 中 / 低
判断依据：最多 3 条
需要补充：最多 3 项数据
建议动作：接受 / 拆分授权后重谈 / 要求补发或保量 / 暂缓
```

若用户只提供了“粉丝量 + 报价 + 时长/周期”，也必须给出初步判断；不要强制索要完整数据。输出应明确哪些部分是基于前置基准、哪些部分是根据后续内容自主推断。

若用户只要求“给个价”，仍至少输出一个主报价区间、一个保守下限和三个价格假设，不伪装成精确市场报价。
