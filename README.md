# 红人营销相关 Skills

这是一组用于红人营销、创作者 Brief、报价判断和个人创作者内容工作的 Codex Skills。

## 目录说明

```text
skills/
├── creator-brief-writer/       创作者 Brief 的拆解、撰写、审核与适配
├── influencer-rate-quoting/    YouTube / Instagram / TikTok 等平台的红人报价与预算判断
└── suisui-ai-career-creator/   “碎碎念狂魔呀”账号的 AI 求职、出海营销与内容工作流

references/                     模板、原始资料包与 Brief 写作逻辑
examples/                       报价判断、红人建联与展示案例
```

## 使用方式

将需要的 Skill 文件夹复制到 Codex 的 skills 目录，或直接在支持 Skill 的工作区中引用对应的 `SKILL.md`。

每个 Skill 的 `SKILL.md` 包含：

- 适用场景与不适用场景
- 默认工作流程
- 输出结构和质量检查点
- 需要用户补充的信息

## 文件说明

- `skills/`：可执行的 Skill 定义，是本仓库的核心内容。
- `references/`：辅助模板、资料包和方法论文档，不会被当作系统指令自动执行。
- `examples/`：用于理解 Skill 输出形式的 PDF、PPTX 和 HTML 案例。

## 来源与整理注释

- `creator-brief-writer`：来自本地 `skills/creator-brief-writer`。
- `influencer-rate-quoting`：来自本地 `skills/influencer-rate-quoting`；同时保留一份资料包中的 `SKILL.md` 作为 `SKILL_PACKAGE.md`，便于对照版本。
- `suisui-ai-career-creator`：来自本地“碎碎念狂魔 AI 求职博主工作流”。
- 参考资料来自本地“红人报价判断 Skill 资料包”、海外红人 Brief 与建联案例文件。

参考资料中的 PDF、PPTX、HTML、ZIP 仅用于阅读和复用，不是额外的操作指令。
